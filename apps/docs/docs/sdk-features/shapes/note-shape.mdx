A note (sticky-note) shape would be a fixed-size coloured card that auto-sizes its text — the staple of brainstorming boards.

**Planned — not yet available** as a built-in element type.

Adjacent capabilities that exist today: `TextElement` for plain text content, `TemplateElement` for host-defined card components, and the annotation/comment layer in `@oh-just-another/scene` (`Annotation`, `Comment`, `addAnnotation`) for pinned discussion. A sticky note could be built as a `TemplateElement` until a first-class note type ships.
