**Planned — not yet available.**

The Chat kit would pair a conversational sidebar with the canvas: you describe
what you want in natural language, and the assistant edits the diagram in place
through the editor's programmatic handle.

This kit is not built yet. The underlying capability it depends on — an AI agent
driving the editor — is documented in the **Agent** kit, which grounds the
pattern in shipped exports. The Chat kit will layer a chat UI and a message loop
on top of that pattern once it is packaged. No chat-specific API exists today, so
none is documented here. Follow the Agent kit for the closest available starting
point.
