Cursor chat would let a collaborator type a short message that floats next to their live cursor for other people in the room to read.

**Planned — not yet available.**

What exists today is the awareness layer in `@oh-just-another/collab`: `CollabAwareness` broadcasts each peer's presence (`Peer`, `PeerUser`), and `bindAwareness` renders peer cursors and selection halos. Ephemeral per-cursor chat messages could be carried over the same awareness channel once designed, but no such API is shipped yet.
