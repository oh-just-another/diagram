**Planned — not yet available.**

The Workflow kit would turn the canvas into a flow builder: nodes are steps,
edges define order and data flow, and the resulting graph can be executed or
exported as an automation.

This kit is not built yet. No workflow-specific API exists today, so none is
documented here. The pieces it would build on already exist — `@oh-just-another/scene`
constructs node-and-link graphs with pure functions, and its layout helpers
(`treeLayout`, `gridLayout`, `runAutoLayout`) arrange them — as shown in the
**Agent** kit. This page will be filled in once the kit is packaged.
