Mixed-type selections now follow the reference behaviour: the floating toolbar SHRINKS to the shared actions (z-order / align / duplicate / comment / lock) instead of showing per-type controls, and gains a Filter popover listing the selection's type buckets (Shapes / Sticky notes / Text / Images / Frames / Drawings / Emoji) with counts — picking one narrows the ACTUAL selection to that bucket, after which the full per-type toolbar returns.
