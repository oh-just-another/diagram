Documentation and editor UI are **English-only for now**. Localization is planned but not yet implemented.

## Status

There is no i18n layer in the editor or this docs site today. The editor chrome (toolbar, menus, panels) renders fixed English labels, and these docs are authored in English.

## Planned

We intend to add translations once the public API and UI strings stabilize. The docs site runs on Docusaurus, whose i18n tooling will host translated content, and the editor's user-facing strings will be made overridable so hosts can supply their own copy.

If you would like to help translate the docs or the UI, open an issue to coordinate: https://github.com/oh-just-another/diagram
