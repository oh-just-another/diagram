**Planned — not yet available.**

The Shader kit would expose a node-based editor for composing GPU shaders
visually — wiring inputs, operations, and outputs into a graph that compiles to a
running shader previewed live on the canvas.

This kit is not built yet. No shader-specific API exists today, so none is
documented here. The editor already auto-detects and uses a WebGL2 backend for
rendering (see the **Agent** and **Multiplayer** kits for how scenes are built
and rendered), but a dedicated shader-authoring surface is not part of the
current packages. This page will be filled in once the kit is packaged.
