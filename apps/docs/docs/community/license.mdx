`@oh-just-another/editor` and every package in the project are released under the **MIT License** — free for any use, including commercial, with no strings attached.

## What this means

- **Free for everyone.** Use it in personal, open-source, and commercial products alike.
- **No license key.** There is nothing to activate. The editor never gates features behind a key or phones home.
- **No production gate.** The exact build you `pnpm add` is the one you ship — development and production behave identically.
- **No mandatory watermark.** Any branding is optional and removable (e.g. the `repositoryUrl` Help-menu link can be hidden with `repositoryUrl={null}`).

```tsx
// No key, no gate — just import and ship.
import { Editor } from "@oh-just-another/editor";
```

## How the project is funded

Monetization is through sponsorship, not by gating the software. The library stays fully open and free; if it helps you, sponsorship is what keeps it maintained — never a license fee.

## Full text

The complete license lives in the `LICENSE` file at the repository root: https://github.com/oh-just-another/diagram. The MIT terms also apply to all contributions (see the Contributing page) — there is no CLA.
